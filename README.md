# Vidrieria Tucuman PRO - Sistema de órdenes por m²

URL Preview: https://fernandezduranfernando1987-code.github.io/vidriera-tucuman-pro/

## Cómo correrlo
Es un solo index.html, no necesita instalar nada. Se abre directo o con Live Server.

## Datos de ejemplo
Todos los datos son inventados, verosímiles, no reales. 13 órdenes de ejemplo cargadas desde seed en localStorage (Kiosco El Sol Yerba Buena, Mariela Diaz Tafí Viejo, etc). Precios de ejemplo del briefing en pesos.

## Configuración
En /admin o #admin se puede cambiar:
- Mínimo facturable m² (default 0.25 m²) - Criterio 3
- Precio colocación (default 30.000)

Clave actual: tucuman2026 - se cambia en localStorage key vt_cfg o en el código.

## Funciones extra
- WhatsApp con texto editable
- Descarga .ics para medición
- Cola urgencias agrupada por localidad
